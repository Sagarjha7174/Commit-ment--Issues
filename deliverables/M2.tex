\section{Current approach and changes since M1}
The architecture of M1 is unchanged: a deterministic engine (\texttt{scenario\_builder.build}) is the \emph{only}
writer of numbers; ML models plug in as services with provenance \emph{modelled}; the LLM only explains engine results
and turns what-if questions into validated engine requests. Changes since M1, each recorded as a numbered decision:
\begin{itemize}
\item \textbf{Engine v2/v3.} Segment-aware NEED impacts (empirical-Bayes shrinkage by EPC band, age, type, region);
savings for electrically heated homes from NEED benchmarks; a NEED-calibrated reference figure shown \emph{next to}
the engineering estimate for combined packages (answering the 5.6--13.8\,pp gap found at M1); boiler efficiency from the
EPC heating rating; field SCOP 2.80 (2.44--3.5); roof-type-aware loft rule (flat roof $\Rightarrow$ no loft);
\textbf{bills} at the Ofgem cap, \textbf{grants} (Boiler Upgrade Scheme), net cost, payback and an
\emph{illustrative} loan; 300-draw Monte Carlo ranges (P10--P90, P(bill falls)); portfolio ranking options.
\item \textbf{ML layer (new).} Shared feature layer (one code path for homes, past certificates and sales; parsed EPC
descriptions); four model families trained with Optuna (seed 42, deterministic LightGBM), gated on validation against
simple baselines; models stored as LightGBM text + metadata; every model version enters the scenario id.
\item \textbf{LLM layer integrated.} The LLM never sees a number: it writes \texttt{\{placeholders\}} that code fills
from an address-free payload with a stable key per engine value. A rule checker drops bad sentences and patches gaps from
a template; a new \textbf{number checker} matches every number in the final answer to an engine value (one regeneration,
then template). What-ifs (measures, tariffs, grants, partial heat pump, own meter reading, ranges, budget) are validated
by the engine's own \texttt{ScenarioRequest} schema; invalid requests are refused with the reason.
\item \textbf{API.} FastAPI: \texttt{/homes/\{id\}/score}, \texttt{/scenario}, \texttt{/explain} (answer, cited values,
scenario id, grounded), \texttt{/whatif}, \texttt{/portfolio}. Works without an LLM key (template explainer).
\end{itemize}

\begin{itemize}
\item \textbf{SAP model:} monotone in every ``better state'' input; on 10,000 homes no fabric, glazing, controls or PV
upgrade lowers the modelled SAP. It powers the indicative ``E $\rightarrow$ D'' shown next to the score. A heat pump can
\emph{lower} SAP (electricity priced above gas), which the explanation states.
\item \textbf{Value:} hedonic $\beta_{\mathrm{SAP}}$ = +0.19\% of price per SAP point (sector-clustered bootstrap 0.11--0.27\%,
99.6\% positive). Demo home A: indicative +1.0\% to +4.2\%; reported as an association, not a causal effect.
\item \textbf{Energy:} banded NEED features leave little signal beyond cell medians, so the gate fails and the engine
keeps the benchmark; the quantile models ship and feed the Monte Carlo.
\item \textbf{Recommender:} per-measure PR-AUC 0.90--1.00 vs 0.59--0.98 for prevalence (thermostat 0.51 vs 0.19);
heat pump has 23 training labels, so rules only. Agreement means ``consistent with the EPC assessor'', not ``feasible''.
\item \textbf{Weak slices} (flagged at $>$1.5$\times$ overall error): SAP at EPC F/G (MAE 9--10), value for flats (15\%).
\end{itemize}

\section{Progress on testing}
\begin{itemize}
\item \textbf{719 automated tests, all passing} (\texttt{make test}): hand-calculated demo homes to $10^{-6}$,
reconciliation, monotonicity of every sub-score, feature contract (no label or address column can reach a model),
privacy guard (address columns never loaded), metrics against hand values, ML services with tiny synthetic models
(abstain paths, determinism, scenario id changes with a model version), API routes, number checker, what-if validation.
\item \textbf{Leakage controls:} encoders and tuning on train only; value features from the certificate lodged
\emph{before} the sale; test scored once by a script that refuses to run twice; counterfactual pairs from held-out homes.
\item \textbf{Fixed since M1:} three tests encoded loft insulation for demo A, whose certificate records a flat roof
(infeasible under our own roof rule); updated by hand arithmetic, not by the engine.
\end{itemize}
